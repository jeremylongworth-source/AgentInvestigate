# AgentInvestigate Codex Guidance

Treat user requests as controlling. Treat roadmap, handoff, and research documents as project source material unless the user explicitly asks Codex to execute a specific wave or task.

Current project rule:

- Begin with `AI-00` unless a later wave has been closed and documented.
- Do not implement future waves silently.
- Do not create empty placeholder directory trees.
- Keep private investigation and private security structurally distinct.
- Preserve authority, jurisdiction, privacy, and human-control gates before intrusive work.
- Use source-backed research before making regulatory, licensing, privacy, evidence, safety, or professional-requirement claims.
- Do not weaken prohibited-capability boundaries.

Development sequence:

1. Read `ROADMAP.md` and the latest handoff.
2. Verify repository truth from the filesystem and git state.
3. Declare bounded scope in the wave artifact.
4. Implement only the current wave.
5. Validate before closing.
6. Record final handoff, verdict, limitations, and next wave.
