# Security Policy

Report security or safety issues through GitHub Issues unless the issue includes sensitive information. Do not post secrets, private personal information, credentials, or exploit details publicly.

AgentInvestigate must not provide procedural assistance for prohibited capabilities such as unauthorized access, credential theft, lock bypass, illegal tracking, stalking, impersonation, coercion, camera or alarm defeat, weapons use, restraint techniques, or combat techniques.

For safety-sensitive or regulated content, prefer conservative routing, explicit jurisdiction requirements, human review, and authoritative source verification.
