# Escalation Routing Reference

## When To Read

Read this reference before using `identify-escalation-requirement`.

## Escalation Triggers

- Emergency, injury, threat, fire, life safety, force, weapons, or restraints.
- Legal, privacy, employment, licensing, or compliance uncertainty.
- Sensitive personal information, surveillance, screening, or monitoring.
- Evidence integrity, contradiction, missing authority, or prohibited request.
- Material consequence for a person or organization.

## Output Boundary

Name the trigger, reviewer, stop condition, and safe handoff. Do not provide the escalated professional's final decision.
