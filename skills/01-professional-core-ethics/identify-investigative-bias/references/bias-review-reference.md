# Bias Review Reference

## When To Read

Read this reference before using `identify-investigative-bias`.

## Bias Indicators

- Predetermined conclusion.
- Loaded or accusatory wording.
- Unsupported intent or credibility inference.
- Ignored contrary evidence.
- Missing alternative explanations.
- Uneven source treatment.
- Scope drift toward a preferred outcome.

## Review Output

Name the risk, point to affected language or evidence, suggest neutral wording, and identify what evidence or review is needed.
