# Fact And Inference Reference

## When To Read

Read this reference before using `separate-fact-from-inference`.

## Classification Labels

- `fact`: source-supported statement.
- `allegation`: claim requiring review.
- `assumption`: unstated or unverified premise.
- `inference`: interpretation from facts.
- `contradiction`: conflicting source material.
- `unknown`: missing fact that matters.

## Rule

When uncertain, use the lower-confidence label and explain what evidence would change the classification.
