Professional skillsets compose existing atomic skills into role-level systems. They do not duplicate underlying skill procedures and do not create new investigative, security, legal, licensing, compliance, emergency, force, weapons, restraint, engineering, fire, or life-safety authority.

The canonical AI-32 registry is:

```text
skillsets/professional-skillsets.json
```

The registry defines each roadmap skillset's purpose, included skills, routing triggers, dependencies, jurisdiction requirements, authority requirements, sensitivity limits, escalation rules, expected outputs, and excluded responsibilities.

Future role-level changes must update the registry, validation, and handoff together.
